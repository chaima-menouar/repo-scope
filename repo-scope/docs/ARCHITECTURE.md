# RepoScope architecture

## Runtime flow

```text
Dashboard or CLI
      |
      v
RepoProfile / FastAPI
      |
      +---- GitHub REST client
      |        |- token auth
      |        |- Link-header pagination
      |        |- primary/secondary rate-limit errors
      |        `- TTL JSON cache
      |
      +---- Analysis engine
      |        |- descriptive stats
      |        |- bus factor
      |        |- health score
      |        |- alerts
      |        |- time series
      |        `- comparison
      |
      +---- Insight layer
      |        |- deterministic explainable summary
      |        `- optional OpenAI Responses API analyst
      |
      `---- Output
               |- responsive dashboard
               |- JSON API
               |- standalone HTML report
               `- CLI export
```

## Health score

The 0–100 score is explainable and weighted rather than generated by an LLM:

- Recent activity: 30 points
- Contributor resilience / bus factor: 20 points
- Issue hygiene: 15 points
- Pull-request hygiene: 10 points
- Engineering practices (CI, tests, license, contributing, README): 20 points
- Stale-issue/community signal: 5 points

Archived repositories are capped because their maintenance status is explicit.

## Sampling strategy

Interactive analysis limits pagination with `GITHUB_MAX_PAGES` (default 3 pages, up to 100 items/page). That protects response time and API quota. The UI labels activity/issue/PR/contributor data as sampled where appropriate.

## Cache

Each endpoint payload is stored as a TTL JSON object. Local runs write under `db/`. On Vercel, RepoScope writes to `/tmp/repo_scope_cache`; this is a warm-instance optimization, not durable storage.

A later cloud data layer can replace this cache with DynamoDB/Postgres without changing the analysis modules.

## AI boundary

The optional LLM receives only normalized aggregate repository metrics and alerts. The deterministic health score remains the source of truth. If no AI key is configured or the AI provider fails, the product remains fully usable.
